# AKAUSE - Moda para os pés

Quero criar uma loja de sapatos femininos online chamada Akause - moda para os pés, focada na venda de sandalias, sapatilhas, saltos, botas, enfim, a vibe da loja é algo bem organico, moderno, as cores primarias são verde e magenta. o site precisa funcionar baseada em uma integração via webhoook "https://www.revendadecalcados.com.br/xmldrop". Essa URL deve ser acessada apenas 1 vez por dia, nela temos acesso a todo estoque de produtos e a partir dela todo o processo de atualização de estoque. É bem provavel que vc não vai conseguir acessa-la por isso eu estou te enviando um csv que tbm é disponibilizado todo dia e aqui vai uma prévia de como o conteudo é exibido no xml diario.

A finalização da compra deve ser por pedido via WhatsApp.

O token privado da URL que informei deve ser solicitado por um formulário seguro de segredo do projeto e mantido como segredo, nunca exposto no código ou no navegador.
